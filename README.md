# 📝 Сайт "To-Do List" 

Мой личный проект **"To-Do List"** (с *англ.* "Список дел") на чистом JavaScript.
Сайт полностью адаптивный и с различными анимациями.

Сайт доступен по [ссылке](https://todo-ordetal.vercel.app) на Vercel.

## ⚙️ Функционал

- 📱 Адаптивный дизайн
- ➕ Добавление задачи
- ✅ Отметка о выполнении задачи
- 🎯 Поддержка Enter-клавиши и автофокуса 
- 🗑️ Удаление одной или всех задач
- 🔄 Drag-and-drop (перетаскивание задач)
- 💬 Toast-уведомления
- 🔢 Счетчик количества задач
- 🌗 Переключение темы
- 💾 Сохранение всех данных в localStorage


## 🔑 Как запустить

Сохраните проект с помощью команды `git clone https://github.com/ordetal/todo-vanilla.git` (или любым другим известным
вам способом) и откройте файл ***`src/index.html`***.

## Как работать

Для того чтобы **scss** скомпилировался в **css**, я использовал расширение в VS Code **"Live Sass Compiler"**, Вы же можете использовать любой другой удобный для вас инструмент сборки.
